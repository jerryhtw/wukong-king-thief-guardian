# Wukong: King, Thief, Guardian · development log

The illustrated development log (Glass Box) for **Wukong: King, Thief, Guardian**, a solo entry by
Ryan Ham (team Banana-Makes-Sense) in the 2026 Epic AI MegaJam.

**Read it:** https://jerryhtw.github.io/wukong-king-thief-guardian/

This repository holds only the static site: `index.html`, styles, scripts and web fonts in
`assets/`, figures in `images/`, and short cutscene loops in `video/`. There is no build step;
GitHub Pages serves the files as they are (`.nojekyll`).

All times in the log are Korea Standard Time. The fonts are Cormorant Infant and Barlow Condensed
under the SIL Open Font License (see `assets/OFL.txt`).
